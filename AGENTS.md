# Project instructions

- This is a public Omarchy work-panel project. Never commit credentials, mail
  contents, account identifiers, private endpoints or local diagnostic dumps.
- Follow the parent machine instructions, including Mise and the machine log.
- Keep packaged Omarchy files untouched; use user-owned plugin/configuration.
- Preserve the normal bar and unrelated shell configuration.
- Reuse the existing work Gmail and Connections widgets and their backends.
  Do not recreate authentication or copy private dashboard code into this project.
- Treat work-mode UI visibility and background polling as separate policies.
- Validate plugin hosting and popup behavior before committing to an architecture.
- Keep issue acceptance criteria and documentation aligned with implementation.
