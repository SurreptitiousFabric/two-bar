# Validate companion-panel architecture

Confirm that a user-owned panel can host existing Omarchy widgets while the standard top bar remains active.

## Acceptance criteria

- [ ] Verify registry discovery when a widget is absent from the top layout.
- [ ] Verify theme imports, required bar host properties, startup loading and IPC ownership.
- [ ] Prototype mounting one synthetic widget and tearing it down without duplicate timers or handlers.
- [ ] Document the chosen architecture and tested Omarchy/Quickshell versions; use a custom two-surface bar host only if the companion approach is insufficient.
