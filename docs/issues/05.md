# Add reversible installation and lifecycle checks

Make local installation, upgrades and removal safe to repeat.

## Acceptance criteria

- [ ] Install only into user-owned paths and preserve unrelated shell configuration.
- [ ] Back up changed configuration and document restoration without overwriting later unrelated edits.
- [ ] Handle enable/startup, reload, disable and uninstall cleanly.
- [ ] Test repeated installation, missing dependencies, reload, toggles, popup teardown and monitor hotplug.
- [ ] Document verified runtime versions, tool pins and manual verification results.
