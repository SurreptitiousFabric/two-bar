# Integrate the existing work Gmail widget first

Move the existing work Gmail indicator to the work panel while preserving its backend.

## Acceptance criteria

- [ ] Depend on the existing monitor rather than copying private source, account data or credentials.
- [ ] Mount exactly one Gmail widget in work mode and remove its top-bar entry only after the panel is validated.
- [ ] Preserve unread count, zero state, health/staleness feedback, left-click open and right-click refresh.
- [ ] Verify hide/show and reload behavior using synthetic status data where possible.
- [ ] Keep unrelated plugins in their current top-bar positions and provide rollback for the Gmail layout change.
