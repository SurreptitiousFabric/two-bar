# Add independent work-mode visibility controls

Let the owner make the work bar disappear when not working.

## Acceptance criteria

- [ ] Resolve manual control versus scheduling with the owner.
- [ ] Provide show, hide, toggle and status operations with idempotent show/hide.
- [ ] Resolve initial state and restart/login persistence.
- [ ] On hide dismiss all work popups/tooltips, remove input and reserved-space footprint, and avoid duplicate instances on show.
- [ ] Document separately whether backend polling continues; do not stop mail services or connections implicitly.
- [ ] Provide a discoverable control and, if selected, a collision-checked keyboard shortcut.

## Sequence

First milestone; depends on architecture issue #1.
