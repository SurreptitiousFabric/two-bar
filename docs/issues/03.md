# Add weekday schedule, keyboard shortcut and Omarchy menu controls

Show the work bar automatically Monday–Friday, 08:00–18:00, with a keyboard
shortcut and an Omarchy trigger-menu toggle for manual control.

## Acceptance criteria

- [ ] Schedule on from 08:00 inclusive to 18:00 exclusive, Monday–Friday in the machine's local timezone; weekends off. No holiday calendar in the initial version.
- [ ] Provide show, hide, toggle, status and follow-schedule operations with idempotent show/hide.
- [ ] Add a collision-checked keyboard shortcut and an Omarchy trigger-menu toggle, both using the same control path. Include “Follow schedule” and visible automatic/manual status in the menu.
- [ ] Implement the proposed manual override until the next actual schedule boundary, subject to owner adjustment; never immediately undo a manual toggle during periodic schedule evaluation.
- [ ] Persist override state and expiry across shell restart/login; discard expired overrides and compute the current scheduled state on startup/resume.
- [ ] Recompute correctly after missed boundaries, clock/timezone changes and DST; use local calendar times.
- [ ] Test weekday boundaries, weekends, overrides, returning to schedule and restart/resume with an injectable clock.
- [ ] On hide dismiss all work popups/tooltips, remove input and reserved-space footprint, and avoid duplicate instances on show.
- [ ] Document separately whether backend polling continues; do not stop mail services or connections implicitly.

## Sequence

First milestone; depends on architecture issue #1.
